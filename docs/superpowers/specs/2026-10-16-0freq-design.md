# ∅FREQ — design

U-Hackathon 2026 · сдача 16.10 14:00 ICT · один разработчик · треки AI + Web3

## Зачем
В 2026 голос клонируется за минуту — сам голос больше не доказывает «это я».
∅FREQ превращает голос артиста в необратимую абстрактную звуковую подпись (частоту),
которую автор сам оформляет в абстрактном стиле и закрепляет за собой в блокчейне.
Для артистов и креаторов по всему миру; первое сообщество — BVLK (Бангкок, FIELD/001 31.10).

## Решения пользователя
- Название **∅FREQ**, эстетика BVLK (монохром, терминал, ∅). UI на английском.
- Пользователь: артисты/креаторы мира; BVLK — первый кейс.
- Подача в оба трека: AI и Web3.
- **Голос не покидает устройство.** Анализ и синтез в браузере. Наружу — только геном (числа) и хэш.
- Запись-сканер: **ॐ поётся скольжением снизу вверх (4–5 с)**, затем голосом мантра
  *ॐ सच्चिदानंदपरब्रह्मपुरुषोत्तमपरमात्मा* — Om Saccidānanda Parabrahma Puruṣottama Paramātmā (6–8 с).
  На экране: деванагари + транслитерация по слогам + подсказка «тянуть / говорить».
- **Пространство абстракции, не пресеты.** Карта XY (X: тон↔шум, Y: непрерывно↔рвано) + 3 ползунка
  (темно↔светло, плотность, пространство). На карте ориентиры-стили (drone, dark ambient, harsh noise,
  power electronics, glitch, microsound, lowercase, musique concrète, granular, spectral, West Coast/FM,
  industrial, IDM, tape/hauntology…). Стартовая точка — куда поставил голос. Можно уйти в безымянную точку.
- **Human-gate:** человек слушает, двигает точку, жмёт «this is my frequency» и подписывает кошельком.
  Без этого ничего не минтится.
- Выход: зацикленный сэмпл 15 с (WAV) + сигил (монохромный, Лиссажу/осциллограф).
- On-chain (Avalanche **Fuji**): непередаваемый токен, **один на кошелёк**, полностью on-chain:
  хэш генома + геном + координаты стиля + SVG-сигил. Звук = «партитура», движок пересобирает его из рецепта.
- ElevenLabs: (а) Sound Effects-слой по тексту из генома+стиля (голос не отправляется);
  (б) голос «Системы» (TTS), объявляет результат на языке пользователя.
- Tokenomist — не в билде; одна фраза в питче: «следующий вход движка — экономика токенов».
- Next.js, одно приложение, Vercel. Без Turborepo.
- Приоритет при нехватке времени: 1) ядро звука → 2) минт → 3) ElevenLabs. Vercel+README — в любом случае.
- Ключей пока нет: ядро строится без ключей; ElevenLabs и минт подключаются, когда появятся.

## Пайплайн
1. **Запись** (MediaRecorder/Web Audio), 2 фазы с таймером.
2. **Геном** (Meyda, по кадрам, агрегаты):
   F0 мин/макс/медиана (автокорреляция) · форманты/огибающая (MFCC 13, средние) · спектральный центроид ·
   flatness · rolloff · джиттер/шиммер (вариативность F0/RMS) · ритм (онсеты RMS на фазе мантры).
   Геном квантуется → keccak256 → seed.
3. **Движок** (Tone.js / Web Audio), модули: осцилляторы с гармониками из MFCC · FM · фильтрованный шум
   на частотах формант · грануляция исходной записи (только локально) · фидбэк/дисторшн · резонатор · реверб.
   Геном задаёт характер модулей (тоника = F0 медиана → ближайшая нота, лад из соотношений, ряд гармоник,
   глубина FM, шум, пульс). Координаты стиля задают микс и поведение модулей. Seed = детерминизм.
4. **Сигил** — SVG из тех же данных.
5. **Gate → минт** — подпись кошельком, вызов контракта.

## Не-цели
Биометрический логин (голос нестабилен) · хранение голоса · IPFS · токен/экономика · Tokenomist в билде.

## Анти-цели
Голос уходит на сервер · результат звучит как пресет/жанр · минт без явного решения человека.

## Мои решения (проверь)
- Контракт: ERC-721 soulbound, `mint(genome, coords, svg)`; tokenURI — base64 JSON on-chain. Деплой через viem + solc-js (Foundry не установлен).
- Кошелёк в браузере через injected provider (Core / MetaMask), сеть Fuji (chainId 43113).
- Ключ ElevenLabs только на сервере (API route), в браузер не попадает.
- Ориентиры на карте — ~16 точек; дополнительные оси (органика↔синтетика, стабильно↔хаотично) — позже.

## UI (из BVLK.EXE, по просьбе пользователя)
- Токены `@bvlk/design/tokens.css` (монохром #050505 / #e8e8e8, зерно 0.045, plate-exposure, ui-plate, ui-scale, ui-xray), шрифты 3270 / 3270 Condensed / Departure Mono / Aldrich (копия файлов шрифтов из bvlk.exe).
- Правила BVLK: монохром без акцента; формы = плотность точек (сигил как BULK SIGNATURE, f(θ), seeded); без длинных тире в копирайте; разделитель ` / `, пустое значение `∅`; без DECRYPT/HACK/CYBER/NEURAL; без фейкового терминала, сканлайнов, неона; CSS Modules + custom properties, без Tailwind.
- Сигил: точки по f(θ), гармоники и амплитуды из генома, рассеивание (dispersal) из координат стиля (шум/фрагментация).
- Код знака пишется заново для ∅FREQ (правило хакатона: нельзя существующий проект); переиспользуются только бренд-ассеты и токены.
